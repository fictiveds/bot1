# Генератор Экспериментальной Музыки

Этот Python-скрипт предназначен для создания странных звуковых файлов и экспериментальных музыкальных композиций. Он использует различные техники генерации и обработки звука для получения уникальных и непредсказуемых результатов.

## Возможности

*   Генерация базовых звуковых волн: синус, квадрат, пила, шум.
*   Применение различных аудиоэффектов:
    *   Задержка (Delay/Echo)
    *   Фильтрация (Low-pass, High-pass)
    *   Реверберация (упрощенная)
    *   Гранулярный синтез (упрощенный)
*   Смешивание и наложение множества звуковых слоев.
*   Создание полноценных композиций со случайным панорамированием и применением эффектов.
*   Управление через интерфейс командной строки (CLI).

## Установка

1.  Клонируйте репозиторий (или просто скачайте файл `sound_generator.py`).
2.  Убедитесь, что у вас установлен Python 3.x.
3.  Установите необходимые зависимости. Рекомендуется использовать виртуальное окружение:

    ```bash
    python -m venv venv
    source venv/bin/activate  # для Linux/macOS
    # venv\Scripts\activate  # для Windows
    ```
4.  Установите библиотеки из файла `requirements.txt`:

    ```bash
    pip install -r requirements.txt
    ```
    Вам также может потребоваться установить `ffmpeg` для работы `pydub` с различными аудиоформатами (хотя для WAV он обычно не нужен). Инструкции по установке `ffmpeg` можно найти на [официальном сайте](https://ffmpeg.org/download.html).

## Использование

Скрипт запускается из командной строки. Убедитесь, что вы находитесь в корневой директории проекта (`experimental_sound_generator`).

**Основные аргументы:**

*   `-o ИМЯ_ФАЙЛА`, `--output_file ИМЯ_ФАЙЛА`: Имя выходного WAV-файла для композиции (по умолчанию: `experimental_music.wav`).
*   `-d ДЛИТЕЛЬНОСТЬ`, `--duration ДЛИТЕЛЬНОСТЬ`: Длительность композиции в секундах (по умолчанию: `30`).
*   `-l КОЛИЧЕСТВО_СЛОЕВ`, `--layers КОЛИЧЕСТВО_СЛОЕВ`: Количество слоев в композиции (по умолчанию: `5`).
*   `--seed SEED`: Целочисленное значение для инициализации генератора случайных чисел (для воспроизводимости результатов).
*   `-s ИМЯ_ФАЙЛА_ЗВУКА`, `--single_sound_file ИМЯ_ФАЙЛА_ЗВУКА`: Сгенерировать один случайный звук и сохранить его в указанный файл (вместо полной композиции).

**Примеры команд:**

1.  **Сгенерировать композицию по умолчанию (30 секунд, 5 слоев) и сохранить в `experimental_music.wav`:**
    ```bash
    python -m cli.main
    ```

2.  **Сгенерировать 60-секундную композицию с 10 слоями и сохранить в `my_composition.wav`:**
    ```bash
    python -m cli.main -o my_composition.wav -d 60 -l 10
    ```

3.  **Сгенерировать композицию с использованием определенного зерна для случайности:**
    ```bash
    python -m cli.main --seed 42
    ```

4.  **Сгенерировать один случайный звук и сохранить его в `random_sound.wav`:**
    ```bash
    python -m cli.main -s random_sound.wav
    ```

## Структура кода

Проект имеет следующую структуру:

*   **`experimental_sound_generator/`**: Корневая папка.
    *   **`cli/main.py`**: Точка входа приложения, обработка аргументов командной строки.
    *   **`composer/composition.py`**: Логика создания музыкальных композиций.
    *   **`audio_engine/`**: Пакет для низкоуровневых операций со звуком.
        *   `waveforms.py`: Генерация базовых звуковых волн (NumPy).
        *   `effects.py`: Реализация аудиоэффектов (NumPy).
        *   `pydub_utils.py`: Утилиты для работы с `pydub`, конвертация и обертки для `AudioSegment`.
    *   **`utils/constants.py`**: Общие константы (например, `SAMPLE_RATE`).
    *   `requirements.txt`: Список зависимостей.
    *   `README.md`: Этот файл.
    *   `.gitignore`: Файл для исключения ненужных файлов из Git.

## Работа с Нодальным Звуковым Движком (Экспериментально)

Помимо основной системы генерации композиций, в проект добавлен начальный функционал **нодального (модульного) звукового движка**. Эта система позволяет создавать звук путем соединения различных модулей обработки и генерации сигналов в единый граф.

Это более гибкий подход, который находится в стадии активной разработки.

### Основные концепции

*   **`Module` (из `nodal_engine.core`)**: Базовый строительный блок. Каждый модуль имеет имя, входы (`inputs`) и выходы (`outputs`).
*   **`AudioModule` (из `nodal_engine.core`)**: Тип модуля, который производит или обрабатывает аудио. Его основной аудио-выход обычно называется `'audio'`.
    *   Примеры: `SineOscillator`, `SquareOscillator`, `DelayEffect` (из `nodal_engine.modules`).
*   **`ControlModule` (из `nodal_engine.core`)**: Тип модуля, который генерирует управляющие сигналы (например, LFO). Его основной выход обычно называется `'value'`.
    *   Примеры: `LFO` (из `nodal_engine.modules`).
*   **`SoundGraph` (из `nodal_engine.graph`)**: Контейнер для модулей. Он управляет их соединениями и процессом рендеринга (генерации) итогового аудио.

### Как это работает (на примере из CLI)

Вы можете протестировать нодальный движок с помощью опции `--nodal_example` в командной строке. Например:

```bash
python -m cli.main --nodal_example пример_нодального_звука.wav
```

Эта команда выполняет следующий код (упрощенно, логика находится в `cli/main.py`):

1.  **Создается граф:**
    ```python
    from nodal_engine.graph import SoundGraph
    from nodal_engine.modules import SineOscillator, LFO
    from utils.constants import SAMPLE_RATE # Глобальная частота дискретизации

    graph = SoundGraph()
    ```

2.  **Создаются и настраиваются модули:**
    ```python
    # LFO для модуляции амплитуды, колеблется от -0.5 до +0.5 с частотой 2 Гц
    lfo_for_amp = LFO(name="amp_lfo", frequency=2.0, amplitude=0.5) 
    
    # Синусоидальный осциллятор с базовой частотой 220 Гц.
    # Его амплитуда будет управляться выходом LFO.
    # Начальная амплитуда 0.0, чтобы четко слышать модуляцию.
    sine_osc = SineOscillator(name="sine1", frequency=220.0, amplitude=0.0) 
    ```

3.  **Модули добавляются в граф:**
    ```python
    graph.add_module(lfo_for_amp)
    graph.add_module(sine_osc)
    ```

4.  **Модули соединяются:**
    *   Выход `'value'` модуля `lfo_for_amp` подключается ко входу `'amplitude'` модуля `sine_osc`.
    ```python
    graph.connect(source_module_name="amp_lfo", source_output_name="value",
                  target_module_name="sine1", target_input_name="amplitude")
    ```
    Теперь LFO будет управлять амплитудой синусоидального осциллятора.

5.  **Назначается мастер-выход:**
    *   Звук с выхода `'audio'` модуля `sine_osc` будет финальным звуком графа.
    ```python
    graph.set_master_output("sine1")
    ```

6.  **Рендерится аудио:**
    *   Граф генерирует 5 секунд аудио с заданной частотой дискретизации.
    ```python
    duration = 5.0  # секунд
    output_audio_segment = graph.render_audio(duration, SAMPLE_RATE)
    ```

7.  **Результат сохраняется в файл.**

### Дальнейшее развитие

Текущая реализация нодального движка является базовой. В планах:
*   Добавление большего количества модулей (генераторов, эффектов, управляющих модулей на основе математических функций).
*   Более сложная система маршрутизации и управления параметрами.
*   Возможность использовать выходы одних `AudioModule` как управляющие сигналы для других (например, амплитудное огибание).
*   Улучшение производительности и обработки блоков.

Вы можете экспериментировать, создавая свои графы программно, по аналогии с примером в `cli/main.py`.
