# Генератор Экспериментальной Музыки

Этот Python-скрипт предназначен для создания странных звуковых файлов и экспериментальных музыкальных композиций. Он использует различные техники генерации и обработки звука для получения уникальных и непредсказуемых результатов.

## Возможности

*   Генерация базовых звуковых волн: синус, квадрат, пила, шум.
*   Применение различных аудиоэффектов:
    *   Задержка (Delay/Echo)
    *   Фильтрация (Low-pass, High-pass)
    *   Реверберация (упрощенная)
    *   Гранулярный синтез (упрощенный)
*   Смешивание и наложение множества звуковых слоев.
*   Создание полноценных композиций со случайным панорамированием и применением эффектов.
*   Управление через интерфейс командной строки (CLI).

## Установка

1.  Клонируйте репозиторий (или просто скачайте файл `sound_generator.py`).
2.  Убедитесь, что у вас установлен Python 3.x.
3.  Установите необходимые зависимости. Рекомендуется использовать виртуальное окружение:

    ```bash
    python -m venv venv
    source venv/bin/activate  # для Linux/macOS
    # venv\Scripts\activate  # для Windows
    ```
4.  Установите библиотеки из файла `requirements.txt`:

    ```bash
    pip install -r requirements.txt
    ```
    Вам также может потребоваться установить `ffmpeg` для работы `pydub` с различными аудиоформатами (хотя для WAV он обычно не нужен). Инструкции по установке `ffmpeg` можно найти на [официальном сайте](https://ffmpeg.org/download.html).

## Использование

Скрипт запускается из командной строки. Убедитесь, что вы находитесь в корневой директории проекта (`experimental_sound_generator`).

**Основные аргументы:**

*   `-o ИМЯ_ФАЙЛА`, `--output_file ИМЯ_ФАЙЛА`: Имя выходного WAV-файла для композиции (по умолчанию: `experimental_music.wav`).
*   `-d ДЛИТЕЛЬНОСТЬ`, `--duration ДЛИТЕЛЬНОСТЬ`: Длительность композиции в секундах (по умолчанию: `30`).
*   `-l КОЛИЧЕСТВО_СЛОЕВ`, `--layers КОЛИЧЕСТВО_СЛОЕВ`: Количество слоев в композиции (по умолчанию: `5`).
*   `--seed SEED`: Целочисленное значение для инициализации генератора случайных чисел (для воспроизводимости результатов).
*   `-s ИМЯ_ФАЙЛА_ЗВУКА`, `--single_sound_file ИМЯ_ФАЙЛА_ЗВУКА`: Сгенерировать один случайный звук и сохранить его в указанный файл (вместо полной композиции).

**Примеры команд:**

1.  **Сгенерировать композицию по умолчанию (30 секунд, 5 слоев) и сохранить в `experimental_music.wav`:**
    ```bash
    python -m cli.main
    ```

2.  **Сгенерировать 60-секундную композицию с 10 слоями и сохранить в `my_composition.wav`:**
    ```bash
    python -m cli.main -o my_composition.wav -d 60 -l 10
    ```

3.  **Сгенерировать композицию с использованием определенного зерна для случайности:**
    ```bash
    python -m cli.main --seed 42
    ```

4.  **Сгенерировать один случайный звук и сохранить его в `random_sound.wav`:**
    ```bash
    python -m cli.main -s random_sound.wav
    ```

## Структура кода

Проект имеет следующую структуру:

*   **`experimental_sound_generator/`**: Корневая папка.
    *   **`cli/main.py`**: Точка входа приложения, обработка аргументов командной строки.
    *   **`composer/composition.py`**: Логика создания музыкальных композиций.
    *   **`audio_engine/`**: Пакет для низкоуровневых операций со звуком.
        *   `waveforms.py`: Генерация базовых звуковых волн (NumPy).
        *   `effects.py`: Реализация аудиоэффектов (NumPy).
        *   `pydub_utils.py`: Утилиты для работы с `pydub`, конвертация и обертки для `AudioSegment`.
    *   **`utils/constants.py`**: Общие константы (например, `SAMPLE_RATE`).
    *   **`nodal_engine/`**: Пакет для нодального (модульного) звукового движка.
        *   `core.py`: Базовые классы `Module`, `AudioModule`, `ControlModule`.
        *   `modules.py`: Конкретные реализации модулей (осцилляторы, эффекты, LFO, ADSR).
        *   `graph.py`: Класс `SoundGraph` для управления графом модулей и рендеринга.
    *   `requirements.txt`: Список зависимостей.
    *   `README.md`: Этот файл.
    *   `.gitignore`: Файл для исключения ненужных файлов из Git.

## Работа с Нодальным Звуковым Движком (Экспериментально)

Помимо основной системы генерации случайных композиций, в проект интегрирован начальный функционал **нодального (модульного) звукового движка**. Этот подход позволяет конструировать звук путем соединения различных модулей (генераторов, эффектов, управляющих сигналов) в единый "звуковой граф". Это открывает путь к более контролируемому и гибкому созданию звуковых текстур и эффектов.

Система находится в стадии разработки, и ее возможности будут расширяться.

### Основные концепции

*   **Модули (`Module`)**: Фундаментальные блоки для построения звука. Расположены в `nodal_engine.modules`.
    *   **`AudioModule`**: Генерируют или обрабатывают аудио (например, `SineOscillator`, `DelayEffect`).
    *   **`ControlModule`**: Создают управляющие сигналы для изменения параметров других модулей (например, `LFO`, `ADSREnvelope`).
*   **`SoundGraph`**: Контейнер из `nodal_engine.graph`, который управляет модулями, их соединениями и процессом генерации (рендеринга) итогового аудио.
*   **Соединения**: Выходы одних модулей могут быть подключены к входам других, позволяя, например, LFO управлять частотой осциллятора или огибающей управлять громкостью.

### Новые модули (Примеры)

*   **`ADSREnvelope`**: Классическая ADSR-огибающая (Attack, Decay, Sustain, Release). Запускается методами `trigger_on()` и `trigger_off()` и генерирует управляющий сигнал, обычно используемый для формирования амплитуды звука во времени.
*   **`SignalScalerOffset`**: Утилитарный модуль, который принимает входной управляющий сигнал, масштабирует его (умножает на коэффициент `scale`) и смещает (добавляет значение `offset`). Полезен для приведения выхода одного модуля (например, LFO с диапазоном -1 до 1) к нужному диапазону для параметра другого модуля (например, частоты осциллятора).

### Пример использования нодального движка

Протестировать нодальный движок можно с помощью опции `--nodal_example` в командной строке. Эта команда создает предопределенный звуковой граф.

```bash
python -m cli.main --nodal_example пример_нодального_звука.wav
```

**Что происходит в этом примере:**

1.  Создается **LFO** (низкочастотный осциллятор), генерирующий плавные колебания.
2.  Сигнал этого LFO обрабатывается модулем **`SignalScalerOffset`**, который преобразует колебания LFO в желаемый диапазон изменения частоты (например, от 220 Гц до 440 Гц).
3.  Этот преобразованный сигнал управляет частотой **синусоидального осциллятора (`SineOscillator`)**, заставляя его тон плавно повышаться и понижаться.
4.  Одновременно создается **ADSR-огибающая (`ADSREnvelope`)**, которая формирует общую громкость звука: быстрая атака, небольшой спад до уровня поддержки (sustain), и затем звук обрывается (так как для простоты примера не реализовано динамическое "отпускание клавиши" для фазы release в рамках одного вызова рендера).
5.  Звук осциллятора, модулированный по частоте и амплитуде, рендерится в WAV-файл.

В результате вы должны услышать звук, высота которого периодически меняется, и который имеет характерное для ADSR-огибающей изменение громкости в начале.

### Дальнейшее развитие

Нодальный движок будет развиваться: планируется добавление новых модулей, улучшение системы маршрутизации и управления параметрами, а также оптимизация производительности. Вы можете экспериментировать, модифицируя код в `cli/main.py` для создания собственных звуковых графов.
